Questions

Good questions.
Simple answers.

Do I have to pick a template?

No. New projects start on an empty canvas. You choose every element, the structure, the content and the style.

Do I need to know how to code?

No. Everything works with clicks and drag-and-drop. If you do know code, you can edit the HTML and CSS directly.

How does the AI help?

It reads your project brief and a text outline of your page, then suggests layout directions with simple steps. It never edits your page on its own — you can add a suggested empty structure if you want one.

Can I edit a website I already have?

Yes. Choose “Edit an existing website” and upload its HTML file or a saved Oakline project. For safety, scripts, forms, embeds and external stylesheets are removed, so you may need to re-add some styles and images.

Is my work saved?

Always in this browser. With a free account it also saves to the cloud, so you can open it on any device. You can download an editable project file as a backup at any time.

Does Oakline host my website?

Not yet. You download your website as an HTML file and can upload it to any hosting provider you like.
